# بورس — اطلاعات پالایش‌شده

این پوشه فقط از داده‌های ثبت‌شده در `runtime/بورس_خام` تغذیه می‌شود.

قانون مسیر داده:

`runtime/بورس_خام → runtime/بورس_پالایش`

در این لایه بعداً پاک‌سازی، استانداردسازی، محاسبه شاخص‌ها و تحلیل انجام می‌شود.

**ممنوع:** اتصال مستقیم این لایه به TSETMC برای جایگزین کردن داده خام.
