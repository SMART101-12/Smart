# بورس — اطلاعات خام

این پوشه تنها محل نگهداری داده‌ای است که مستقیماً از TSETMC دریافت می‌شود.

قانون مسیر داده:

`TSETMC → runtime/بورس_خام → پالایش بعدی`

هیچ محاسبه، رتبه‌بندی، اندیکاتور، اصلاح یا تغییر مقدار در این لایه انجام نمی‌شود.

هر دریافت در فایل/مسیر جداگانه با زمان دریافت ثبت می‌شود تا داده خام قابل بازبینی و بازسازی باشد.
