# پالایش — مرحله ۱ تحلیل و بک‌تست

این مرحله فقط از سابقه قیمت ذخیره‌شده از **TSETMC** در Git استفاده می‌کند. برای قیمت یا حجم از جست‌وجوی اینترنتی استفاده نمی‌شود.

## روش

1. همه رکوردهای روزانه موجود در `runtime/history/پالایش/` خوانده و بر اساس `dEven` مرتب می‌شوند.
2. سیگنال در پایان هر روز و فقط با داده‌های همان روز و روزهای قبل ساخته می‌شود؛ بنابراین سیگنال به آینده نگاه نمی‌کند.
3. افق ارزیابی پیش‌بینی ۵ روز معاملاتی است.
4. شاخص‌های مرحله اول: SMA5/SMA20/SMA50، EMA12/EMA26، RSI14، MACD، ATR14، نسبت حجم به میانگین ۲۰ روزه، ROC20 و افت از سقف ۶۰ روزه.
5. بک‌تست تک‌تک شاخص‌ها جداگانه و یک امتیاز ترکیبی انجام می‌شود.
6. نقاط حساس شامل کراس میانگین‌ها، اشباع RSI، جهش حجم، شکست سقف/کف ۲۰ روزه و افت حداقل ۱۵٪ از سقف ۶۰ روزه ثبت می‌شوند.

## خروجی

اجرای زیر گزارش و CSVهای مرحله اول را در `runtime/analysis/` می‌سازد:

```powershell
$env:PYTHONPATH = ".\src"
.\.venv\Scripts\python.exe -m smart.technical_analysis پالایش
```

فایل‌های خروجی:

- `runtime/analysis/پالایش_analysis.json` — خلاصه روش، دقت شاخص‌ها، دقت مدل ترکیبی و نقاط حساس
- `runtime/analysis/پالایش_signals.csv` — یک ردیف برای هر روز و تمام ویژگی‌ها/پیش‌بینی‌ها
- `runtime/analysis/پالایش_sensitive_points.csv` — نقاط حساس تاریخی

## قانون مهم برای مرحله بعد

عدد دقت به‌تنهایی ملاک انتخاب اندیکاتور نیست. در مرحله بعد تعداد سیگنال، بازده بعد از سیگنال، عملکرد در روند صعودی/نزولی و خطاهای متوالی بررسی می‌شود تا وزن‌دهی SMART بر اساس شواهد تاریخی انجام شود.

هر تغییر مربوط به این مسیر باید با commit جداگانه در Git ثبت شود تا زنجیره تصمیمات و نسخه‌ها قابل بازگشت باشد.
